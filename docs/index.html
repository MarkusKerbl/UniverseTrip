UniverseTrip

UniverseTrip is an interactive 3D visualization program for displaying cosmic objects across the entire observable universe.

Test it online now!

  • 🔭 3D-Visualisierung astronomischer Objekte mit Plotly
  • 🧠 Filter nach Helligkeit, Entfernung, Objekttyp
  • 🖥️ Einfache GUI mit Tkinter
  • 📁 Export als HTML-Plot für die Weitergabe
