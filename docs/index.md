# Willkommen bei UniverseTrip 🚀

Dies ist ein Tool zur interaktiven Darstellung astronomischer Objekte im sichtbaren Universum.

- Filterung nach Helligkeit, Entfernung, Objekttyp
- Ausgabe als 3D-Plot (Plotly)
- Steuerung über eine Tkinter-GUI

👉 [Zum GitHub-Repository](https://github.com/MarkusKerbl/UniverseTrip)
