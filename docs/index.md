    <h1>🚀 UniverseTrip</h1>

    <p><strong>UniverseTrip</strong> ist ein Python-Tool zur interaktiven Visualisierung des sichtbaren Universums. Es bietet eine leistungsstarke Kombination aus Plotly für 3D-Darstellungen und einer intuitiven GUI zur Filterung astronomischer Objekte.</p>

    <ul>
      <li>🔭 3D-Visualisierung astronomischer Objekte mit Plotly</li>
      <li>🧠 Filter nach Helligkeit, Entfernung, Objekttyp</li>
      <li>🖥️ Einfache GUI mit Tkinter</li>
      <li>📁 Export als HTML-Plot für die Weitergabe</li>
    </ul>
